# FloryGuardBot 🛡️

Модульный Discord-бот безопасности и комплексной защиты сообществ от рейдов, крашей, спама и несанкционированных действий администрации.

---

## ⚡ Основные возможности

* **Anti-Nuke & Admin Guard**:
  * Мониторинг Discord Audit Logs в реальном времени.
  * Мгновенное снятие прав и изоляция нарушителя при несанкционированном бане участников.
  * Автоматический откат (rollback) при удалении/создании/изменении каналов и ролей.
  * Откат несанкционированной выдачи/снятия ролей через контекстное меню (ПКМ).
  * Система страйков: 5 предупреждений с автоматическим снятием через 7 дней. На 5/5 — автоматическое снятие всех ролей и перевод в карантин.
  * Разрешенные действия модерации (муты, тайм-ауты, удаление сообщений) ботом не блокируются.

* **AutoMod 2.0 & Чат-фильтры**:
  * Блокировка инвайтов (`discord.gg`), сокращателей ссылок (`bit.ly`, `t.me` и др.) и фишинг/скам доменов.
  * Защита от обхода фильтров: удаление Zero-Width символов, Zalgo-текста, нормализация гомоглифов (транслита) и leetspeak.
  * Rate-limiting сообщений по алгоритму Token Bucket (макс. 4 сообщения за 3 секунды с авто-мутом при спаме).
  * Детект дубликатов сообщений по алгоритму расстояния Левенштейна (> 85%).
  * Защита от массовых упоминаний (@everyone, @here, >3 ролей).

* **Anti-Raid**:
  * Детект join-flood (массового входа ботов за короткий интервал).
  * Авто-карантин свежесозданных аккаунтов (младше 24 часов).

* **Иерархия доступа**:
  * `Owner` / `Senior Admin` — полный контроль, команды вайтлиста, админов, выдачи ролей и снимков.
  * `Admin` — доверенные администраторы безопасности (действия не откатываются).
  * `WhiteList` — иммунитет к автомоду и снятию ролей.

* **Снимки и бэкапы (Snapshots)**:
  * Создание снимков структуры каналов, категорий и прав сервера с возможностью восстановления в 1 клик.

## 📁 Структура проекта

```text
├── cogs/
│   ├── admin_guard.py      # Команды вайтлиста, админов, /addrole, /removerole, снимки

│   ├── permissions.py      # Проверка прав и иерархии
│   └── rate_limiter.py     # Token Bucket и Join-Spike трекер
├── database/

│   └── text_scanner.py     # Деобфускация текста, регулярки, Левенштейн
```

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/bsakbs6-dev/floryguard-discord.git
cd floryguard-discord
```

### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение:
```bash
python -m venv venv
# Linux / macOS:
source venv/bin/activate
# Windows:
.\venv\Scripts\activate

pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:
```env
DISCORD_TOKEN=your_bot_token_here
DATABASE_PATH=database/floryguard.db
ENVIRONMENT=production
COMMAND_PREFIX=!fg 
```

### 4. Настройка `config.json`
В `config.json` укажите ID авторизованных серверов и роли изоляции:
```json
{
  "hierarchy": {
    "owner_ids": [1398717669607473254],
    "senior_admin_ids": [1291370925303795733]
  },
  "authorized_guilds": {
    "1480873879181459547": {
      "name": "Server 1",
      "quarantine_role_id": 1542851471274414080,
      "log_channel_id": null
    }
  }
}
```

### 5. Запуск
```bash
python main.py
```

Или через Docker:
```bash
docker compose up -d --build
```

## 🛠️ Настройка прав бота в Discord

1. В **Discord Developer Portal** во вкладке **Bot ➔ Privileged Gateway Intents** включите:
   * `Presence Intent`
   * `Server Members Intent`
   * `Message Content Intent`
2. Пригласите бота с правами **Administrator** (`bot` + `applications.commands`).
3. В **Настройках сервера ➔ Роли** переместите роль бота **на самый верх** списка ролей (выше ролей модераторов и роли карантина), чтобы бот имел право управлять ими.

## 📋 Список слэш-команд

| Команда | Описание | Доступ |
| :--- | :--- | :--- |
| `/profile [user]` | Просмотр профиля безопасности и списка варнов | Все (эфемерно) |
| `/addrole @user @role` | Выдать роль пользователю через бота | Владелец / Ст. Админ |
| `/removerole @user @role`| Снять роль у пользователя через бота | Владелец / Ст. Админ |
| `/warn add @user [reason]`| Выдать предупреждение на 7 дней | Все Админы |
| `/warn remove [id]` | Аннулировать предупреждение по ID | Все Админы |
| `/warn list @user` | Список активных предупреждений игрока | Все Админы |
| `/warn clear @user` | Очистить все предупреждения игрока | Все Админы |
| `/whitelist add @user` | Добавить пользователя в WhiteList | Все Админы |
| `/whitelist remove @user`| Удалить пользователя из WhiteList | Все Админы |
| `/whitelist list` | Показать список участников WhiteList | Все Админы |
| `/admin add @user` | Назначить администратора безопасности | Владелец / Ст. Админ |
| `/admin remove @user` | Снять администратора безопасности | Владелец / Ст. Админ |
| `/admin list` | Список действующих администраторов | Владелец / Ст. Админ |
| `/lockdown [channel/all]` | Заморозить канал или весь сервер | Все Админы |
| `/unlock [channel/all]` | Разблокировать канал или весь сервер | Все Админы |
| `/purge [amount] [user]` | Быстрая очистка чата от спама/ботов | Все Админы |
| `/snapshot create` | Создать снимок структуры сервера | Ст. Админ |
| `/snapshot list` | Список доступных снимков | Ст. Админ |
| `/restore [snapshot_id]` | Восстановить каналы и роли из снимка | Ст. Админ |
